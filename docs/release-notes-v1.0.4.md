# Release Notes - v1.0.4

## Highlights
- Added Ctrl/Shift multi-select for output lines while keeping single-line text selection.
- Added a context menu action to copy selected output lines in view order.

## Details
- Ctrl+C now copies multiple selected output lines when multi-select is active.
- Right-click selects the clicked output line before showing the context menu.

## Notes
- No configuration changes required.
- Output copy still preserves per-line text without merging content across lines.

---

# 发布说明 - v1.0.4

## 亮点
- 支持 Ctrl/Shift 多选输出行，同时保留单行文本选择体验。
- 新增右键菜单，可按显示顺序复制选中输出行。

## 细节
- 多选时按 Ctrl+C 会复制所有选中行。
- 右键会先选中当前行再弹出菜单。

## 备注
- 无需修改配置。
- 复制仍按行输出，不会合并跨行内容。
